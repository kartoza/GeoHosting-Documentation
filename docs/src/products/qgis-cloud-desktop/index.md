# QGIS Cloud Desktop

Your QGIS desktop, hosted in the cloud. Sign in with a passkey from any browser and pick up the exact session you left running — the same projects, plugins, layer styles and unsaved edits, on a workstation-class machine sized for your data.

QGIS Cloud Desktop replaces the cycle of "install QGIS, hunt for the right plugin version, find the dataset, reconfigure the database connection on each machine" with one persistent workspace that follows you. Field teams, students learning QGIS, and analysts who move between offices all get the same desktop without the laptop.
