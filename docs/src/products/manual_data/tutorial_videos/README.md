# Test data for the GeoSpatial Hosting tutorial videos

Each folder holds the files used on screen in one video, with a README that explains what each file is and where it is used.

Downloads in one file (in the `manual_data` folder):

- GeoSight: `Manual_Data_GeoSight.zip`
- GeoServer: `Manual_Data_GeoServer.zip`, folder `tutorial_videos`
- G3W: `Tutorial_Data_G3WSUITE.zip`, folder `tutorial_videos`
- PostGIS: `Manual_Data_PostGIS.zip`, folder `tutorial_videos`

- [GeoSight](geosight/): 9 videos, from a first dashboard to scheduled imports
- [GeoServer](geoserver/): editing layers from QGIS, and SQL view analysis layers
- [G3W](g3w/): publishing PostGIS data, and styling your G3W
- [PostGIS](postgis/): syncing QField edits from the field back to your database

Data marked as fictional was generated for the videos and does not describe real places, people or events. Real open data keeps its original licence; see the Credits section of each README.
